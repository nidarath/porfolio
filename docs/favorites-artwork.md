# Favorites cat cutouts

The four cat images come from the user's screenshot snippets. The built-in image generation tool was used in background-extraction edit mode to remove white backgrounds and detached neighboring fragments. Transparent alpha was preserved when trimming and optimizing the edited outputs as 512 × 512 WebP assets. The prior glossy object set is no longer used by the favorites section.

## tea

Asset: `public/favorites/clover-cat.webp`

### Final edit prompt

Use case: background-extraction. Image 1 is the EXACT EDIT TARGET, not a style reference. The user wants to use this exact screenshot-snipped artwork on a website.
Task: remove ONLY the white background and any screenshot border so the existing character is an isolated transparent cutout. Preserve the original cat image's appearance: same silhouette, pose, proportions, low-poly shapes, soft low-resolution texture, facial expression, whiskers, colors and accessories. Do not redraw, redesign, recolor, beautify, sharpen or replace the character. Do not introduce any new details. Retain the slightly soft original game-model rendering.
Subject to preserve: the reclining white and cream calico cat holding the green four-leaf clover. Keep the whole clover, stem, whiskers and all the cat's visible paws.
Remove the white also inside gaps between accessories, limbs, and between characters. Preserve fine black whiskers and light white fur edge pixels, with a clean natural antialiased alpha edge and no white matte halo. No ground, no drop shadow, no border, no background color. Center the complete original subject with a little transparent padding. The output must have a genuinely transparent background.
